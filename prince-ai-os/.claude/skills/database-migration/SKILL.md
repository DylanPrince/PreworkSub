# Database migration

1. Edit `packages/database/prisma/schema.prisma`. Prefer additive changes; give new required columns a
   default or a backfill.
2. `cd packages/database && npx prisma migrate dev --name <short_snake_case>` against the local dev
   database only. Review the generated SQL in `prisma/migrations/`.
3. Never run `prisma migrate reset`, `db push --force-reset`, or drop statements without the owner's
   explicit approval, and never against a non-local database.
4. `pnpm typecheck` (the client is regenerated by `migrate dev`), then `pnpm test`.
5. Integration/E2E databases are updated with `prisma migrate deploy` by the test setup.
